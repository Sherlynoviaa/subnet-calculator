# Network Subnet Calculator

Aplikasi web sederhana untuk menghitung Network Address, Broadcast Address, Subnet Mask, Jumlah Host, dan Range IP berdasarkan input IP/CIDR.

## Fitur
- Menghitung subnetting menggunakan operasi *bitwise* JavaScript.
- Tampilan UI modern (Dark mode & Glassmorphism).
- Mendukung perlakuan khusus untuk subnet /31 dan /32.
- Responsif dan mudah digunakan.

## Cara Menjalankan
Cukup buka file `index.html` di browser favorit Anda (Chrome, Firefox, dll).

## Teknologi
- HTML5
- CSS3 (Vanilla)
- JavaScript (Vanilla)
